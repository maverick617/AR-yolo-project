# Old Pen

- Title: `Old Pen`
- Author: djetty
- Source: https://sketchfab.com/3d-models/old-pen-7a09c75d40e84b10acfd4f8c40e08375
- License: CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/
- Project source file: `Old Pen 3D Model.glb`

The project copy was converted from the user-provided GLB to Wavefront OBJ for
Unity 2022.3 compatibility. The mesh geometry, UVs, normals, base-color texture,
and normal texture were preserved. The Prefab is reoriented so that the pen tip
points along local `+Y` and is normalized to a nominal length of 14 cm.
